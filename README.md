# ペタペタペンギン団(広告再現版)

「ペタペタペンギン団」のスポンサー広告で流れる映像(円形アリーナで自動攻撃するヒーローが押し寄せる敵を迎撃し、レベルアップ時に「ゴッドキング進化」の二択を選び、ステージ制で敵の侵入を許すと『挑戦失敗』になる)を、実際に遊べるブラウザゲームとして再現したファンメイド版です。

外部アセットや依存ライブラリなしの単一HTML5 Canvasゲームです。

## 遊び方

`index.html` をブラウザで直接開くか、簡易サーバーで配信してください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

### 操作

- ヒーローは中央に立ち、円形の道を進んでくる敵を自動で攻撃します
- 画面タップ / 右下の「スキル」ボタンで範囲スキルを発動(クールダウンあり)
- レベルが5の倍数になると「ルート選択」が発生し、2体の「ゴッドキング」進化先から選択
  - 攻撃力上昇率が高いほど成功確率は下がるリスク・リターン方式
- 祭壇(画面上部)に敵の侵入を許すとライフが減少し、0になるとステージ失敗
- タイマー内に生き残ればステージクリアとなり、次のステージ(最大50)へ進みます

## ファイル構成

- `index.html` - ゲーム画面のマークアップ
- `style.css` - UI・オーバーレイのスタイル
- `game.js` - ゲームロジック全体(Canvas描画、戦闘、進化選択、ステージ進行)
