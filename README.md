# サークルタワーディフェンス

スマホ広告でよく見かける「円形アリーナの『+』マスに兵士を配置し、同じ数字の兵士を合体させて育て、フィールドに出る歯車を攻撃して新しい兵士を仲間にし、数字が『10』になる合体で『ゴッドキング進化』の二択(成功率が低いほど強く進化)を選び、押し寄せる敵を迎撃してステージ制で敵の侵入を許すと『挑戦失敗』になる」というタイプのゲームを、実際に遊べるブラウザゲームとして再現したファンメイド版です。

外部アセットや依存ライブラリなしの単一HTML5 Canvasゲームです。

## 遊び方

`index.html` をブラウザで直接開くか、簡易サーバーで配信してください。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

### 操作

- 円形フィールド内の「+」マスに配置された兵士は、自動でリング上を進む敵の中で最も祭壇に近い敵を攻撃します
  - **攻撃範囲は数字ごとに異なり、1が最も狭く、3・5・10…と数字が大きくなるほど広くなります**。1のキャラはフィールド中央からだとリングまで届かないため、外周付近に置く必要があります
- 同じ数字の兵士を2体タップすると合体し、次の数字の兵士1体になります(例:1+1→3、3+3→5、5+5→10)
  - 合体すると人数は減りますが、1体あたりの攻撃力・射程は上がります(攻撃回数と火力・射程のトレードオフ)
- 兵士を1体タップしてから空きマスをタップすると、その兵士を移動できます
- フィールド上にランダムに出現する歯車には体力(数字)があり、射程内に入った兵士が自動で攻撃します。破壊すると新しい兵士(数字1)が仲間になります
  - 歯車から遠い兵士は敵の迎撃を優先するため、歯車を早く壊すには射程の届く位置に兵士を移動させましょう
- 合体で数字が「10」になると「進化選択」が発生し、2体の「ゴッドキング」進化先から選択します
  - 成功率が低いカードほど、成功時に得られる攻撃力ボーナスが大きくなります
- 祭壇(画面上部)に敵の侵入を許すとライフが減少し、0になるとステージ失敗
- タイマー内に生き残ればステージクリアとなり、次のステージ(最大50)へ進みます

## ファイル構成

- `index.html` - ゲーム画面のマークアップ
- `style.css` - UI・オーバーレイのスタイル
- `game.js` - ゲームロジック全体(Canvas描画、配置・合体・射程・歯車・進化選択、戦闘、ステージ進行)
